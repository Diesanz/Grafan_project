# Grafan Project

## Descripción General
Grafan es un proyecto diseñado para facilitar la creación y gestión de documentos utilizando lenguajes de marcado y programación. El objetivo es proporcionar herramientas eficientes para la generación de documentos técnicos y académicos.

## Lenguajes Principales
- **TeX**: Sistema de tipografía ampliamente usado en documentos científicos y técnicos, ideal para fórmulas matemáticas y control de presentación.
- **Python**: Lenguaje versátil utilizado para análisis de datos, scripting y desarrollo de herramientas auxiliares.

## Instrucciones Básicas de Uso
1. Clona el repositorio:
   ```bash
   git clone https://github.com/Diesanz/Grafan_project.git
   ```
2. Accede al directorio del proyecto:
   ```bash
   cd Grafan_project
   ```
3. Sigue las instrucciones específicas para compilar o ejecutar el código según los archivos disponibles.

## Cómo Contribuir
¡Las contribuciones son bienvenidas!
1. Haz fork del repositorio.
2. Crea una rama para tu mejora:
   ```bash
   git checkout -b nombre-de-tu-rama
   ```
3. Realiza cambios y haz commit:
   ```bash
   git commit -m "Descripción de los cambios"
   ```
4. Haz push de tu rama a tu fork:
   ```bash
   git push origin nombre-de-tu-rama
   ```
5. Abre un pull request en el repositorio original.
